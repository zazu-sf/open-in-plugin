# Changelog

## [1.0.1] - 2026-08-05

### Added

- GitHub Pages workflow publishing a Stash-compatible plugin source.
- Automatically generated versioned ZIP and SHA-256 source index.
- Tag-based GitHub Release workflow.
- Local source-build script and installation documentation.

- Repository-ready first release.
- Renamed to Open In Plugin.
- Moon Player, Infuse, and custom-player integrations.
- Per-app enable checkboxes.
- Dynamic default-app icon and app/source menu.
- Stream and SMB playback.
- Player-aware visibility modes.
- Anonymous defaults and examples.
